# Living Scrapbook — navigation and mobile refinement

Status: user selected B; implemented and deployed to both installations. See the implementation handoff for validation and release details.

These three studies continue the selected Living Scrapbook direction with US-focused fictional family content. Created using the built-in image_gen tool. The Parker family and all photographs are synthetic examples, not customer content.

## Compare

- **A — Paper index:** compact cream rail with colored paper tabs; best for persistent desktop navigation.
- **B — Folder tabs:** horizontal folder navigation; more open canvas and a stronger album metaphor. Recommended after reviewing the rendered comparison because it addresses the user's sidebar concern most directly. The user selected B on September 6, 2026.
- **Mobile:** single-column notes, clear capture action, paper-colored bottom navigation. This establishes a shared mobile direction for either desktop option.

The content set includes a peach photo print, butter story note, blue voice memo, sage milestone and blush capsule. The mobile viewport intentionally shows fewer notes rather than shrinking text to fit everything.

These images are visual references, not tested UI. Exact labels, actual logo asset, audience semantics, focus, playback, safe areas and contrast must be validated in implementation. Card appearance should be deterministic; see the main handoff for details. Do not use synthetic memories inside real archives.

Review notes: the generated paper texture is stronger than intended; simplify it in implementation. A introduces a decorative botanical flourish under the wordmark that is not an approved brand change; use the real logo. The mobile output is a long-feed visual study rather than a literal phone viewport: implement scrolling content and a fixed bottom bar with sufficient padding so the final capsule can be fully read. Keep serif headings but use clear, uncondensed sans-serif body and control text. Handwritten quote accents must not impair readability. These are three separate generations, so the illustrative family photo varies slightly; production previews should reuse one coherent asset set.
