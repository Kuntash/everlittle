# Everlittle product design options

> Current direction: the user selected **02 Living Scrapbook**, with varied sticky-note memories, US-focused fictional content and a lighter, playful navigation treatment. The recommendation below is historical. Continue from [the detailed redesign handoff](../../../docs/living-scrapbook-redesign-handoff.md), which also specifies landing-page motion and rollout to both geteverlittle.com and dikichoetso.com / everlittle-dikichoetso.

Visual studies for selection before implementation. Generated with the built-in image_gen tool. Application code unchanged. Fictional sample content and photography.

## Recommendation

01 Quiet Heirloom: editorial cream and forest, spacious memory-first composition. Recommended foundation, with the clear capture form demonstrated in 03.

02 Living Scrapbook: warm paper, terracotta actions, tactile photo/voice/letter treatments. Closest to the current homepage.

03 Everyday Companion: lighter surfaces, compact chronological rows, straightforward capture. Strongest utility focus.

## Audit and limits

Reviewed live homepage text, app source, theme tokens, existing generated design references, and six SEO guide routes. No connected browser was available; authenticated live screens were not visually tested. No blog implementation was found in this checkout, so article designs are proposed templates pending the actual blog URL/source.

App theme uses paper #f7f1e7, forest #173b32, terracotta #b96e55. Scrapbook homepage and SEO guides use paper #f6efdf, green #365f47, red #c9573f, with blue and yellow accents. Shared Cormorant Garamond and Geist fonts already exist. The redesign should unify semantic colors, typography hierarchy, spacing, buttons, cards and focus treatments across app and public pages.

App scope after selection: parent view, timeline, capture and memory detail, capsules, child space, family/settings, authentication/onboarding, loading/empty/error/success states, desktop and mobile. Then align homepage, pricing, six guides and blog templates while preserving public URLs, metadata, analytics and existing permissions.

## Corrections before implementation

These are generated concept boards, not exact interface specifications. Retain the actual logo asset. Keep public navigation appropriate to public pages (option 01 incorrectly repeats app navigation). Separate Photo and Story (option 02 merges them). Reconcile form fields and visibility options with existing data and access rules. Sample dates, authors, controls and photographic subjects are illustrative. Confirm keyboard behavior, actual text contrast, mobile target sizes, and responsive overflow in implementation; none is validated by an image.
